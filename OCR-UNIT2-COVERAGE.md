## 📝 How to Import to Quizlet

1. Go to [Quizlet.com](https://quizlet.com) and log in
2. Click "Create" → "Study set"
3. Click "Import" (or "Import from Word, Excel, Google Docs, etc.")
4. Select "Custom" for the import format
5. Set:
   - **Between term and definition:** Tab
   - **Between cards:** New line
6. Copy and paste the contents of `quizlet-import-unit2.txt`
7. Click "Import"
8. Review and click "Create"

**Alternative:** You can also:
- Change the separator to "Comma" and use CSV format
- Import directly if you have the file open in a text editor
