# 1.3 Exchanging Data
# 87 flashcards

What is a LAN (Local Area Network)?	A network covering a small geographical area (single building or campus). Characteristics: High speed, owned by single organization, low latency, uses Ethernet or Wi-Fi.
What is a WAN (Wide Area Network)?	A network covering a large geographical area (cities, countries, globally). Characteristics: Lower speed than LAN, uses third-party infrastructure (ISPs), higher latency. The Internet is the largest WAN.
What is the TCP/IP model?	A 4-layer protocol stack for network communication:
1. Application Layer (HTTP, FTP, SMTP, DNS)
2. Transport Layer (TCP, UDP)
3. Internet Layer (IP, routing)
4. Link Layer (Ethernet, Wi-Fi, physical transmission)
What is the Application Layer?	The top layer of TCP/IP stack where network applications and protocols operate. Protocols include HTTP (web), FTP (file transfer), SMTP (email), DNS (domain names). Provides services directly to users.
What is the Transport Layer?	Responsible for end-to-end communication and data delivery. Main protocols:
- TCP (Transmission Control Protocol): reliable, connection-oriented, error-checking
- UDP (User Datagram Protocol): faster, connectionless, no error-checking
What is the Internet Layer?	Handles addressing and routing of data packets across networks. Uses IP (Internet Protocol) to assign addresses and route packets to their destination. Includes IPv4 and IPv6.
What is the Link Layer?	The lowest layer that handles physical transmission of data over network hardware. Includes Ethernet, Wi-Fi, MAC addresses. Deals with physical connections and local network communication.
What is packet switching?	A method where data is broken into small packets that are sent independently across the network and reassembled at destination. Each packet can take different routes. Efficient use of bandwidth, robust, but variable latency.
What is circuit switching?	A method where a dedicated communication path is established between sender and receiver for the entire duration of transmission (like traditional phone calls). Guaranteed bandwidth but inefficient resource use.
What is a protocol?	A set of rules and standards that govern how data is transmitted and received over a network. Ensures different devices can communicate effectively. Examples: HTTP, TCP, IP, FTP.
What is TCP (Transmission Control Protocol)?	A connection-oriented protocol that ensures reliable data transmission. Features: establishes connection (handshake), error-checking, guaranteed delivery, packet ordering, flow control. Used for web browsing, email, file transfer.
What is UDP (User Datagram Protocol)?	A connectionless protocol for fast data transmission without reliability guarantees. No error-checking or delivery guarantee. Used for streaming, gaming, VoIP, DNS where speed is more important than reliability.
What is an IP address?	A unique numerical identifier assigned to each device on a network. IPv4 uses 32 bits (e.g., 192.168.1.1), IPv6 uses 128 bits. Allows devices to be located and communicated with on networks.
What is DNS (Domain Name System)?	A system that translates human-readable domain names (e.g., google.com) into IP addresses that computers use. Acts like a phone book for the internet.
What is a MAC address?	A unique hardware identifier assigned to network interface cards (NICs). 48 bits long, written in hexadecimal (e.g., AA:BB:CC:DD:EE:FF). Used for communication within local networks at the Link Layer.
What is a bitmap image?	An image represented as a grid of pixels (picture elements), where each pixel has a specific color value. File size depends on resolution and color depth. Examples: BMP, PNG, JPEG.
What is resolution in images?	The number of pixels in an image, usually expressed as width × height (e.g., 1920×1080). Higher resolution means more detail but larger file size.
What is color depth/bit depth in images?	The number of bits used to represent the color of each pixel. More bits = more colors possible:
1-bit: 2 colors (black/white)
8-bit: 256 colors
24-bit: 16.7 million colors (8 bits each for Red, Green, Blue)
How do you calculate image file size?	File Size = Width × Height × Color Depth
Example: 1920×1080 image with 24-bit color:
1920 × 1080 × 24 = 49,766,400 bits = 6,220,800 bytes ≈ 6.2 MB
(Before compression)
What is metadata in image files?	Data about the image stored alongside pixel data:
- Image dimensions (width, height)
- Color depth
- Creation date/time
- Camera settings (ISO, shutter speed, aperture)
- GPS location
- Author/copyright
What is the difference between vector and bitmap graphics?	Bitmap: Grid of pixels, loses quality when scaled, larger files for complex images. Used for photos.
Vector: Mathematical equations for shapes/lines, scales without quality loss, smaller files for simple images. Used for logos, illustrations.
What is sound sampling?	The process of converting analog sound waves into digital data by measuring (sampling) the amplitude of the wave at regular intervals. Each measurement is a sample.
What is sample rate?	The number of samples taken per second, measured in Hertz (Hz). Higher sample rate = better quality audio.
CD quality: 44,100 Hz (44.1 kHz)
Human hearing range: up to ~20 kHz
What is bit depth in audio?	The number of bits used to represent each audio sample. Higher bit depth = more precise amplitude values and greater dynamic range.
8-bit: 256 levels
16-bit: 65,536 levels (CD quality)
24-bit: 16.7 million levels (studio quality)
How do you calculate sound file size?	File Size = Sample Rate × Bit Depth × Duration × Number of Channels
Example: 1 minute of CD quality stereo:
44,100 × 16 × 60 × 2 = 84,672,000 bits ≈ 10.6 MB
(Before compression)
What is lossy compression?	Compression that reduces file size by permanently removing some data. Results in smaller files but quality loss. Used when perfect accuracy isn't critical.
Examples: JPEG (images), MP3 (audio), MP4 (video)
What is lossless compression?	Compression that reduces file size without losing any data. Original can be perfectly reconstructed. Larger files than lossy but maintains quality.
Examples: PNG (images), FLAC (audio), ZIP (general)
What is encryption?	The process of converting plaintext (readable data) into ciphertext (unreadable data) using an algorithm and key, to protect data confidentiality during transmission or storage.
What is plaintext and ciphertext?	Plaintext: Original, readable data before encryption (e.g., 'HELLO')
Ciphertext: Encrypted, unreadable data after encryption (e.g., 'KHOOR')
Decryption converts ciphertext back to plaintext.
What is symmetric encryption?	Encryption where the same key is used for both encryption and decryption. Fast and efficient but key distribution is challenging. Examples: AES, DES, Caesar cipher, Vernam cipher.
What is asymmetric encryption?	Encryption using two different keys: a public key (for encryption) and a private key (for decryption). Solves key distribution problem but slower than symmetric. Examples: RSA, Diffie-Hellman. Used for secure key exchange and digital signatures.
What is the Caesar cipher?	A simple substitution cipher where each letter is shifted by a fixed number of positions in the alphabet. Example: with shift of 3, A→D, B→E, HELLO→KHOOR. Easy to break by trying all 25 possible shifts (brute force).
How does the Caesar cipher work with an example?	Shift each letter by key value. Example with key=3:
Plaintext: ATTACK
A→D, T→W, T→W, A→D, C→F, K→N
Ciphertext: DWWDFN
To decrypt, shift backwards by 3.
What is the Vernam cipher (One-Time Pad)?	A theoretically unbreakable encryption method using XOR operation with a random key that is: 1) As long as the message, 2) Truly random, 3) Used only once, 4) Kept secret. Plaintext XOR Key = Ciphertext. Perfectly secure if conditions met.
How does the Vernam cipher work?	Convert plaintext and key to binary, then XOR each bit:
Plaintext: H (01001000)
Key:       K (01001011)
XOR result: (00000011) = Ciphertext
To decrypt: Ciphertext XOR Key = Plaintext
Key must never be reused.
What are the advantages of symmetric encryption?	1. Fast encryption/decryption
2. Efficient for large amounts of data
3. Less computationally intensive
4. Simpler algorithms
What are the disadvantages of symmetric encryption?	1. Key distribution problem (how to securely share key?)
2. Need separate key for each pair of users
3. No authentication of sender
4. If key compromised, all data exposed
What are the advantages of asymmetric encryption?	1. Solves key distribution (public key can be shared openly)
2. Provides authentication (digital signatures)
3. No need to share secret keys
4. Enables secure communication without prior key exchange
What are the disadvantages of asymmetric encryption?	1. Much slower than symmetric encryption
2. More computationally expensive
3. Not suitable for large data
4. Requires longer key lengths for same security
What is a hash function?	A one-way mathematical function that converts input data of any size into a fixed-size output (hash/digest). Properties: deterministic (same input = same output), fast to compute, one-way (cannot reverse), small change creates completely different hash. Used for passwords, data integrity, digital signatures.
What are the properties of a good hash function?	1. Deterministic: same input always produces same hash
2. Fast computation
3. One-way/irreversible: cannot get original from hash
4. Avalanche effect: small input change = completely different hash
5. Collision resistant: hard to find two inputs with same hash
6. Fixed output size
What is a hash collision?	When two different inputs produce the same hash output. While theoretically possible (pigeonhole principle - infinite inputs, finite outputs), good hash functions make collisions extremely rare and computationally infeasible to find intentionally.
What is a hash table?	A data structure that uses hash functions to map keys to array indices for fast data storage and retrieval. Provides O(1) average-case lookup, insertion, and deletion. Used in dictionaries, databases, caches. Handles collisions using chaining or open addressing.
How are hash tables used for password storage?	Passwords are hashed before storage. When user logs in:
1. User enters password
2. System hashes entered password
3. Compares hash with stored hash
4. If match, password correct
Actual password never stored, so data breach doesn't expose passwords. Often uses salt (random data added before hashing) to prevent rainbow table attacks.
What is salting in password hashing?	Adding random data (salt) to passwords before hashing. Each password gets unique salt stored alongside hash. Prevents rainbow table attacks (pre-computed hash tables) and ensures identical passwords have different hashes. Example: hash('password' + 'x7f2k') ≠ hash('password' + 'a9m1p')
What are common uses of hashing?	1. Password storage (secure authentication)
2. Data integrity verification (checksums)
3. Digital signatures
4. Hash tables (data structures)
5. Blockchain/cryptocurrency
6. File deduplication
7. Message authentication codes (MACs)
What is the difference between encryption and hashing?	Encryption: Two-way, reversible with key, preserves data for decryption, used for confidentiality
Hashing: One-way, irreversible, fixed output size, destroys original data, used for integrity and authentication
Encryption protects data in transit/storage; hashing verifies data hasn't changed.
What is a database?	An organized collection of structured data stored electronically, allowing efficient storage, retrieval, modification, and deletion of data. Managed by Database Management Systems (DBMS) like MySQL, PostgreSQL, Oracle.
What is a relational database?	A database organized into tables (relations) with rows (records/tuples) and columns (attributes/fields). Tables can be linked using relationships via primary and foreign keys. Uses SQL for querying. Examples: MySQL, PostgreSQL, Oracle, SQL Server.
What is a primary key?	A unique identifier for each record in a table. Properties: must be unique, cannot be NULL, only one per table. Examples: StudentID, ISBN, CustomerNumber. Ensures each record can be uniquely identified.
What is a foreign key?	A field in one table that references the primary key in another table, creating a relationship between tables. Used to maintain referential integrity. Example: StudentID in 'Enrollments' table references StudentID in 'Students' table.
What is a composite key?	A primary key made up of two or more fields combined to create a unique identifier. Used when no single field is unique. Example: StudentID + CourseID together uniquely identify an enrollment record.
What is SQL?	Structured Query Language - a standard language for managing and manipulating relational databases. Categories: DDL (Data Definition - CREATE, ALTER, DROP), DML (Data Manipulation - SELECT, INSERT, UPDATE, DELETE), DCL (Data Control - GRANT, REVOKE).
What is a SELECT query in SQL?	Retrieves data from database tables.
Basic syntax: SELECT column1, column2 FROM table WHERE condition;
Examples:
SELECT * FROM Students; (all columns)
SELECT name, age FROM Students WHERE age > 16;
SELECT * FROM Students ORDER BY name;
What is an INSERT query in SQL?	Adds new records to a table.
Syntax: INSERT INTO table (column1, column2) VALUES (value1, value2);
Example:
INSERT INTO Students (StudentID, Name, Age) VALUES (101, 'Alice', 17);
Multiple rows:
INSERT INTO Students VALUES (102, 'Bob', 18), (103, 'Carol', 16);
What is an UPDATE query in SQL?	Modifies existing records in a table.
Syntax: UPDATE table SET column1 = value1 WHERE condition;
Example:
UPDATE Students SET Age = 18 WHERE StudentID = 101;
WARNING: Without WHERE, updates ALL records!
What is a DELETE query in SQL?	Removes records from a table.
Syntax: DELETE FROM table WHERE condition;
Example:
DELETE FROM Students WHERE StudentID = 101;
WARNING: DELETE FROM Students; (without WHERE) deletes ALL records!
What are SQL JOIN operations?	Combines rows from two or more tables based on related columns.
INNER JOIN: Returns matching records in both tables
LEFT JOIN: All from left table + matching from right
RIGHT JOIN: All from right table + matching from left
Example: SELECT * FROM Students INNER JOIN Enrollments ON Students.ID = Enrollments.StudentID;
What is database normalization?	The process of organizing database tables to reduce redundancy and improve data integrity. Involves dividing large tables into smaller ones and defining relationships. Reduces data duplication, saves storage, prevents update anomalies.
What is First Normal Form (1NF)?	Requirements:
1. Each cell contains only atomic (single) values
2. No repeating groups or arrays
3. Each record is unique
Example violation: A 'Phone' column containing '123, 456, 789'
Fix: Create separate row for each phone number or separate table.
What is Second Normal Form (2NF)?	Requirements:
1. Must be in 1NF
2. All non-key attributes must depend on the entire primary key (no partial dependencies)
Applies to tables with composite keys. If attribute depends on only part of key, move it to separate table.
Example: In (StudentID, CourseID, StudentName), StudentName depends only on StudentID, not the full key.
What is Third Normal Form (3NF)?	Requirements:
1. Must be in 2NF
2. No transitive dependencies (non-key attributes must not depend on other non-key attributes)
Example violation: Table has StudentID, CourseID, InstructorName where InstructorName depends on CourseID (not StudentID)
Fix: Move InstructorName to separate Courses table.
What are the benefits of normalization?	1. Reduces data redundancy (less duplicate data)
2. Improves data integrity (consistency)
3. Easier to maintain and update
4. Prevents update anomalies
5. Saves storage space
6. Makes database more flexible for queries
What are update anomalies?	Problems in poorly designed databases:
Insertion anomaly: Cannot add data without other data
Deletion anomaly: Deleting data unintentionally removes other data
Update anomaly: Updating data in one place but not others causes inconsistency
Normalization prevents these issues.
What is a database transaction?	A sequence of database operations treated as a single unit of work. Must follow ACID properties: Atomicity (all or nothing), Consistency (valid state), Isolation (concurrent transactions don't interfere), Durability (committed changes persist). Example: bank transfer (debit + credit must both succeed or both fail).
What are ACID properties?	Atomicity: Transaction fully completes or fully fails (no partial)
Consistency: Database remains in valid state before/after
Isolation: Concurrent transactions don't interfere with each other
Durability: Committed changes persist even after system failure
Ensures reliable database transactions.
What is referential integrity?	A database rule ensuring relationships between tables remain consistent. Foreign key values must either match a primary key in referenced table or be NULL. Prevents orphaned records. Example: Can't enroll student in course if StudentID doesn't exist in Students table.
What is HTML?	HyperText Markup Language - the standard markup language for creating web pages. Uses tags to structure content (headings, paragraphs, links, images, etc.). Not a programming language - just defines structure and content. Example: <h1>Title</h1>, <p>Paragraph</p>
What are common HTML tags?	<html> - root element
<head> - metadata, title, links to CSS/JS
<body> - visible page content
<h1> to <h6> - headings
<p> - paragraph
<a href="url"> - hyperlink
<img src="image.jpg"> - image
<div> - division/container
<ul>, <ol>, <li> - lists
<table>, <tr>, <td> - tables
What is CSS?	Cascading Style Sheets - a language for styling and formatting HTML content. Controls appearance: colors, fonts, layouts, spacing, positioning. Separates presentation from content. Can be inline, internal (<style> tag), or external (.css file). Example: h1 { color: blue; font-size: 24px; }
What are the three ways to include CSS?	1. Inline: <p style="color: red;">Text</p>
2. Internal: <style> p { color: red; } </style> in <head>
3. External: <link rel="stylesheet" href="style.css"> in <head>
Best practice: External CSS for maintainability and reusability.
What is JavaScript?	A high-level, interpreted programming language for web development. Adds interactivity and dynamic behavior to websites (form validation, animations, user interactions, DOM manipulation). Runs in browser (client-side) or server (Node.js). Example: button clicks, content updates without page reload.
What is the difference between client-side and server-side?	Client-side: Code runs in user's browser (HTML, CSS, JavaScript). Immediate response, reduces server load, but visible to users (security risk for sensitive operations).
Server-side: Code runs on web server (PHP, Python, Node.js, Java). Secure, accesses databases, processes data, generates dynamic HTML sent to client.
What is the client-server model?	A network architecture where clients (browsers) request resources/services from servers.
1. Client sends HTTP request to server
2. Server processes request
3. Server sends HTTP response (HTML, data)
4. Client displays/processes response
Enables distributed computing and web applications.
What is HTTP?	HyperText Transfer Protocol - the protocol for transmitting web pages and data over the internet. Stateless request-response protocol. Uses methods:
GET (retrieve data)
POST (submit data)
PUT (update)
DELETE (remove)
Runs on port 80.
What is HTTPS?	HTTP Secure - encrypted version of HTTP using SSL/TLS. Encrypts data between client and server, protecting sensitive information (passwords, credit cards). Shows padlock in browser. Essential for security. Runs on port 443. Uses certificates to verify server identity.
What are HTTP status codes?	Server responses indicating request outcome:
200 OK - Success
301 Moved Permanently - Redirect
400 Bad Request - Client error
401 Unauthorized - Authentication required
403 Forbidden - Access denied
404 Not Found - Resource doesn't exist
500 Internal Server Error - Server problem
503 Service Unavailable
What is a URL?	Uniform Resource Locator - web address specifying resource location.
Format: protocol://domain:port/path?query#fragment
Example: https://www.example.com:443/page.html?id=123#section
protocol: https
domain: www.example.com
port: 443 (optional, default for HTTPS)
path: /page.html
query: ?id=123
fragment: #section
What is the DOM (Document Object Model)?	A programming interface representing HTML/XML documents as a tree structure. Each element is a node that can be accessed and manipulated with JavaScript. Allows dynamic page updates without reload. Example: document.getElementById('title').innerHTML = 'New Title';
What are cookies?	Small text files stored on user's computer by websites. Store user preferences, session data, tracking information. Sent with every request to same domain. Types: Session cookies (temporary), Persistent cookies (expire date). Privacy concerns led to GDPR cookie consent requirements.
What is a web server?	Software/hardware that stores, processes, and delivers web pages to clients. Handles HTTP requests, serves static files (HTML, CSS, images), executes server-side code, manages databases. Examples: Apache, Nginx, IIS, Node.js. Listens on ports 80 (HTTP) or 443 (HTTPS).
What is responsive web design?	Designing websites that adapt to different screen sizes and devices (desktop, tablet, mobile). Uses flexible layouts, media queries, fluid grids, scalable images. Ensures good user experience across all devices. Example: @media (max-width: 768px) { /* mobile styles */ }
What are server-side scripting languages?	Languages that run on web servers to generate dynamic content:
PHP - widely used, WordPress
Python - Django, Flask frameworks
JavaScript - Node.js
Ruby - Rails framework
Java - servlets, JSP
Process forms, access databases, generate personalized content, handle authentication.
What is AJAX?	Asynchronous JavaScript and XML - technique for updating parts of web page without reloading entire page. Uses JavaScript to send/receive data from server in background. Creates faster, more interactive web applications. Example: auto-complete search, live notifications, infinite scroll. Modern version uses JSON instead of XML.
What is JSON?	JavaScript Object Notation - lightweight data interchange format. Human-readable text format for structured data. Language-independent but uses JavaScript syntax. Commonly used for APIs and web services.
Example: {"name": "Alice", "age": 17, "grades": [90, 85, 92]}
What is an API (Application Programming Interface)?	A set of rules/protocols allowing different software applications to communicate. Web APIs (REST, GraphQL) enable data exchange between client and server using HTTP. Returns data (usually JSON/XML) instead of HTML. Example: Weather API provides weather data to apps/websites.
What is the difference between GET and POST?	GET:
- Retrieves data from server
- Parameters in URL (visible)
- Can be bookmarked/cached
- Limited data size
- Idempotent (safe to repeat)

POST:
- Sends data to server
- Parameters in request body (not visible in URL)
- Cannot be bookmarked
- No size limit
- Not idempotent (creates/modifies data)
