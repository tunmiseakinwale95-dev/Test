What is abstraction in computational thinking?	The process of removing unnecessary detail and complexity from a problem to focus on the essential features. Involves hiding implementation details and showing only functionality. Examples: using functions without knowing internal workings, database views.
What is decomposition?	Breaking down a complex problem into smaller, more manageable sub-problems that can be solved individually. Makes large problems easier to understand and solve. Each sub-problem can be solved separately and then combined.
What is algorithmic thinking?	Creating a logical sequence of steps to solve a problem. Involves identifying the inputs, processes, and outputs needed. The solution must be clear, unambiguous, and executable.
What is pattern recognition?	Identifying similarities, trends, or regularities in data or problems. Helps in reusing solutions from similar problems. Allows for generalization and use of existing algorithms/solutions.
What is problem recognition?	The ability to identify that a problem exists and understand its nature. Involves defining the problem clearly, identifying constraints, and determining what a successful solution looks like.
What is problem representation?	Expressing a problem in a form suitable for computational solution. May use diagrams, tables, graphs, mathematical notation, or data structures. Good representation makes the problem easier to solve.
What is a subroutine?	A named block of code that performs a specific task and can be called from other parts of the program. Two types: procedures (perform actions) and functions (return values). Benefits: code reuse, modularity, easier testing and maintenance.
What is the difference between a procedure and a function?	Procedure: executes code but doesn't return a value. Used for performing actions (e.g., print, save file). Function: executes code AND returns a value. Used for calculations or data transformations (e.g., calculate total, get user input).
What are parameters?	Variables listed in the subroutine definition that receive values when the subroutine is called. Allow data to be passed into subroutines. Make subroutines more flexible and reusable.
What are arguments?	The actual values passed to a subroutine when it is called. These values are assigned to the parameters. Example: in calculate(5, 10), the arguments are 5 and 10.
What is the difference between local and global variables?	Local variables: declared inside a subroutine, only accessible within that subroutine, destroyed when subroutine ends, prevent naming conflicts. Global variables: declared outside subroutines, accessible throughout the program, persist for program lifetime, can cause unexpected side effects.
What is variable scope?	The region of code where a variable can be accessed. Local scope: variable only accessible within its defining block. Global scope: variable accessible throughout the entire program. Good practice: minimize global variables to avoid conflicts.
What is parameter passing by value?	A copy of the argument's value is passed to the parameter. Changes to the parameter inside the subroutine don't affect the original variable. Safer but uses more memory for large data. Default in many languages.
What is parameter passing by reference?	The memory address of the argument is passed to the parameter. Changes to the parameter inside the subroutine DO affect the original variable. More memory efficient for large data but can cause unintended side effects.
What is a return statement?	A statement that exits a function and optionally sends a value back to the caller. Only used in functions (not procedures). Can return any data type. Execution of function stops when return is reached.
What is modular programming?	A design technique that separates program functionality into independent, interchangeable modules/subroutines. Benefits: easier to understand, test, debug, and maintain; enables code reuse; allows team collaboration.
What is recursion?	A programming technique where a subroutine calls itself to solve a problem by breaking it into smaller instances of the same problem. Must have: base case(s) to stop recursion, recursive case(s) that call the function. Alternative to iteration.
What is a base case in recursion?	The condition that stops the recursion. Returns a value without making another recursive call. Without a base case, recursion continues infinitely causing stack overflow. Example: in factorial, base case is n = 0 or n = 1.
What is a recursive case?	The part of a recursive function that makes a recursive call with a modified parameter, moving towards the base case. Example: in factorial(n), recursive case is n * factorial(n-1).
Give an example of a recursive algorithm	Factorial: function factorial(n) if n <= 1 then return 1 (base case) else return n * factorial(n-1) (recursive case). factorial(5) = 5 * 4 * 3 * 2 * 1 = 120
What are the advantages of recursion?	1. More elegant and readable for certain problems (trees, fractals) 2. Natural fit for recursive data structures 3. Simpler code for complex problems 4. Easier to prove correctness mathematically 5. Good for divide-and-conquer algorithms
What are the disadvantages of recursion?	1. Uses more memory (stack space for each call) 2. Slower than iteration (overhead of function calls) 3. Risk of stack overflow with deep recursion 4. Can be harder to debug 5. Not all problems suit recursive solutions
What is the call stack?	A data structure that stores information about active subroutines. Each function call creates a new stack frame containing local variables, parameters, and return address. Frames are popped when functions return. Recursion creates multiple frames.
What is stack overflow?	An error that occurs when the call stack runs out of memory, typically from excessive recursion without reaching base case or too deep recursion. Crashes the program. Can be avoided with proper base cases and tail recursion optimization.
When should you use recursion vs iteration?	Use recursion for: tree/graph traversal, divide-and-conquer, naturally recursive problems (Fibonacci, factorial), when code clarity is priority. Use iteration for: simple loops, performance-critical code, large datasets, when stack space is limited.
Give an example of recursive binary search	function binarySearch(array, target, low, high) if low > high then return -1 (not found) mid = (low + high) / 2 if array[mid] = target then return mid (found) else if target < array[mid] then return binarySearch(array, target, low, mid-1) else return binarySearch(array, target, mid+1, high)
What is an abstract data type (ADT)?	A theoretical concept that defines a data type by its behavior (operations) rather than its implementation. Specifies what operations can be performed but not how they are implemented. Examples: Stack, Queue, List, Dictionary. Implementation details are hidden.
What is a stack ADT?	A Last-In-First-Out (LIFO) abstract data type. Operations: push(item), pop(), peek(), isEmpty(). Applications: function calls, undo operations, expression evaluation, backtracking algorithms.
How can you implement a stack?	1. Using an array: fast access, fixed size, need to track top pointer 2. Using a linked list: dynamic size, slightly slower, no size limit. Both implementations should support push, pop, peek, isEmpty operations.
What is a queue ADT?	A First-In-First-Out (FIFO) abstract data type. Operations: enqueue(item), dequeue(), peek(), isEmpty(). Applications: task scheduling, print queues, breadth-first search, buffer management.
How can you implement a queue?	1. Linear queue (array): simple but wastes space as front moves 2. Circular queue (array): efficient use of space, wraps around 3. Linked list: dynamic size, no wraparound issues, slight overhead. All should support enqueue, dequeue, peek, isEmpty.
What is a priority queue?	A queue where each element has a priority value. Elements with higher priority are dequeued before lower priority elements, regardless of insertion order. Applications: task scheduling, Dijkstra's algorithm, event simulation. Often implemented using heaps.
What is a dictionary/map ADT?	An abstract data type storing key-value pairs. Each key is unique and maps to one value. Operations: insert(key, value), get(key), delete(key), containsKey(key). Also called associative array or hash map. Fast lookups by key.
What is a set ADT?	An unordered collection of unique elements (no duplicates). Operations: add(element), remove(element), contains(element), union, intersection, difference. Applications: removing duplicates, membership testing, mathematical set operations.
What is a graph ADT?	A data structure consisting of vertices (nodes) and edges connecting them. Can be directed or undirected, weighted or unweighted. Operations: addVertex, addEdge, removeVertex, removeEdge, getNeighbors. Applications: networks, maps, social connections.
What is a tree ADT?	A hierarchical data structure with a root node and child nodes forming a parent-child relationship. No cycles. Types: binary tree, binary search tree, AVL tree. Applications: file systems, databases, expression parsing, decision making.
What is a binary tree?	A tree data structure where each node has at most two children: left child and right child. Each node contains data, pointer to left child, pointer to right child. Root is the top node. Leaf nodes have no children.
What is a binary search tree (BST)?	A binary tree with ordering property: for each node, all values in left subtree are less than node's value, all values in right subtree are greater. Enables efficient searching, insertion, deletion. Average case O(log n) for balanced trees.
What are the three tree traversal methods?	1. In-order (Left, Root, Right): visits nodes in ascending order for BST 2. Pre-order (Root, Left, Right): useful for copying tree structure 3. Post-order (Left, Right, Root): useful for deleting tree or evaluating expressions
Describe in-order traversal algorithm	function inOrder(node) if node is not null then inOrder(node.left), visit(node), inOrder(node.right). For BST: produces values in ascending order.
Describe pre-order traversal algorithm	function preOrder(node) if node is not null then visit(node), preOrder(node.left), preOrder(node.right). Useful for: copying tree, prefix expressions.
Describe post-order traversal algorithm	function postOrder(node) if node is not null then postOrder(node.left), postOrder(node.right), visit(node). Useful for: deleting tree, postfix expressions, calculating tree properties.
How do you insert into a binary search tree?	Start at root. Compare value with current node: If less: go left (if left is null, insert here). If greater: go right (if right is null, insert here). If equal: handle duplicates. Time complexity: O(log n) average, O(n) worst case (unbalanced).
How do you search in a binary search tree?	Start at root. Compare target with current node: If equal: found! If less: search left subtree. If greater: search right subtree. If null: not found. Time complexity: O(log n) average, O(n) worst case.
What is tree depth/height?	Depth of a node: number of edges from root to that node (root has depth 0). Height of tree: maximum depth of any node (longest path from root to leaf). Height of empty tree is -1, single node tree has height 0.
What is a balanced binary tree?	A tree where the height difference between left and right subtrees of any node is at most 1. Ensures O(log n) performance for operations. Examples: AVL trees, Red-Black trees. Unbalanced trees can degrade to O(n) performance.
What is a graph?	A data structure consisting of vertices (nodes) connected by edges. Can represent networks, relationships, maps. Components: vertices/nodes, edges/arcs. Can be directed (one-way edges) or undirected (two-way edges).
What is a weighted graph?	A graph where each edge has an associated numerical value (weight) representing cost, distance, time, etc. Used in shortest path algorithms (Dijkstra's). Example: road network with distances as weights.
What is an adjacency matrix?	A 2D array representation of a graph where matrix[i][j] = 1 if edge exists from vertex i to j, 0 otherwise. For weighted graphs, stores weight instead of 1. Space: O(V²). Good for dense graphs. Fast edge lookup O(1).
What is an adjacency list?	A graph representation where each vertex stores a list of its adjacent vertices. Space: O(V + E). Good for sparse graphs. Slower edge lookup than matrix but more space-efficient. Easier to iterate over neighbors.
What is depth-first search (DFS)?	A graph traversal algorithm that explores as far as possible along each branch before backtracking. Uses a stack (or recursion). Applications: detecting cycles, topological sorting, maze solving, finding connected components.
Describe the DFS algorithm	function DFS(vertex) mark vertex as visited, for each neighbor of vertex do if neighbor not visited then DFS(neighbor). Iterative version uses explicit stack. Time: O(V + E).
What is breadth-first search (BFS)?	A graph traversal algorithm that explores all neighbors at current depth before moving to next depth level. Uses a queue. Applications: shortest path in unweighted graphs, level-order traversal, finding connected components.
Describe the BFS algorithm	function BFS(start) create queue Q, mark start as visited, enqueue start. while Q not empty: dequeue vertex, for each neighbor if not visited: mark visited, enqueue. Time: O(V + E).
What are the differences between DFS and BFS?	DFS: Uses stack, goes deep, less memory for sparse graphs, doesn't find shortest path. BFS: Uses queue, goes wide, finds shortest path in unweighted graphs, more memory usage. Both: O(V + E) time complexity.
What is Dijkstra's algorithm?	An algorithm for finding the shortest path from a start vertex to all other vertices in a weighted graph with non-negative weights. Uses a priority queue. Greedy algorithm. Time: O((V + E) log V) with binary heap. Applications: GPS, network routing.
What is object-oriented programming (OOP)?	A programming paradigm based on objects that contain data (attributes) and code (methods). Key principles: encapsulation, inheritance, polymorphism. Benefits: modularity, reusability, easier maintenance, models real-world entities.
What is a class?	A blueprint or template for creating objects. Defines attributes (data) and methods (behavior) that objects of that class will have. Example: Car class with attributes (color, model) and methods (drive, brake). Classes are abstract, objects are concrete.
What is an object?	An instance of a class. Has its own set of attribute values but shares methods defined in the class. Example: myCar is an object of class Car. Created using constructor. Also called an instance.
What is encapsulation?	Bundling data and methods that operate on that data within a class, hiding internal details. Uses access modifiers (private, public, protected). Benefits: data protection, implementation hiding, easier to change internal code without affecting external code.
What are access modifiers?	Keywords controlling visibility of class members: Public (accessible from anywhere), Private (only accessible within the class), Protected (accessible within class and subclasses). Good practice: make attributes private, provide public methods (getters/setters).
What is inheritance?	Mechanism where a new class (subclass/child) inherits attributes and methods from an existing class (superclass/parent). Enables code reuse and hierarchical classification. Subclass can add new features or override existing ones. Example: Dog inherits from Animal.
What is a superclass (parent class)?	The class being inherited from. Contains common attributes and methods shared by subclasses. Also called base class. Example: Animal is superclass of Dog, Cat, Bird. More general than subclasses.
What is a subclass (child class)?	A class that inherits from a superclass. Inherits all non-private members of parent. Can add new attributes/methods or override inherited ones. Also called derived class. Example: Dog is subclass of Animal. More specific than superclass.
What is polymorphism?	The ability of objects of different classes to respond to the same method call in different ways. Two types: overriding (runtime) and overloading (compile-time). Enables flexible code. Example: different animals respond differently to speak() method.
What is method overriding?	When a subclass provides a specific implementation of a method already defined in its superclass. Same method name, parameters, and return type. Subclass version is called for subclass objects. Example: Dog.speak() overrides Animal.speak().
What is method overloading?	Multiple methods in same class with same name but different parameters (number, type, or order). Return type can differ. Compiler determines which version to call based on arguments. Example: print(int), print(string), print(int, int).
What is a constructor?	A special method called when an object is created. Initializes object attributes. Same name as class, no return type. Can be overloaded. If none defined, default constructor is provided. Example: Car(color, model).
What is the 'this' keyword?	A reference to the current object. Used to: distinguish between parameters and attributes with same name, pass current object to other methods, call other constructors. Example: this.name = name (parameter assigns to attribute).
What is aggregation?	A 'has-a' relationship where one class contains objects of another class as attributes. Container and contained objects can exist independently. Example: Car has Engine, but Engine can exist without Car. Weaker relationship than composition.
What is composition?	A strong 'has-a' relationship where contained objects cannot exist independently of container. When container is destroyed, contained objects are too. Example: House has Rooms - destroying House destroys its Rooms. Stronger than aggregation.
What is Big O notation?	Mathematical notation describing algorithm efficiency by expressing how runtime or space requirements grow with input size n. Focuses on worst-case scenario and growth rate, ignoring constants. Examples: O(1), O(log n), O(n), O(n²).
What is O(1) - Constant time?	Algorithm takes same time regardless of input size. Examples: array access by index, hash table lookup (average), push/pop on stack. Most efficient.
What is O(log n) - Logarithmic time?	Algorithm runtime increases logarithmically with input size. Doubles input only adds one more operation. Very efficient for large datasets. Examples: binary search, balanced BST operations.
What is O(n) - Linear time?	Algorithm runtime increases proportionally with input size. Double input, double time. Examples: linear search, traversing array/list, finding min/max. Acceptable for most purposes.
What is O(n log n) - Linearithmic time?	Algorithm runtime is n multiplied by log n. Common in efficient sorting algorithms. Examples: merge sort, quick sort (average), heap sort. Much better than O(n²).
What is O(n²) - Quadratic time?	Algorithm runtime is proportional to square of input size. Often involves nested loops. Examples: bubble sort, insertion sort, selection sort. Inefficient for large datasets.
What is O(2ⁿ) - Exponential time?	Algorithm runtime doubles with each addition to input. Very inefficient. Examples: recursive fibonacci without memoization, generating all subsets. Quickly becomes impractical.
What is O(n!) - Factorial time?	Algorithm runtime is factorial of input size. Extremely inefficient. Examples: generating all permutations, traveling salesman brute force. Only practical for very small inputs (n < 12).
Compare common Big O complexities	From best to worst: O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!). For n=100: O(1)=1, O(log n)=7, O(n)=100, O(n²)=10000 operations.
How do you determine time complexity?	1. Count operations as function of n 2. Keep fastest-growing term 3. Drop constants and coefficients. Example: 3n² + 5n + 2 → O(n²). Nested loops often indicate O(n²). Dividing problem in half suggests O(log n).
What is space complexity?	Amount of memory an algorithm uses relative to input size. Uses same Big O notation. Includes: variables, data structures, recursion stack. Trade-off: often can reduce time by using more space (memoization).
What is the time complexity of common operations?	Array access: O(1), Array search: O(n), Binary search: O(log n), Bubble sort: O(n²), Merge sort: O(n log n), Hash table get/put: O(1) average.
What is bubble sort?	Simple sorting algorithm that repeatedly steps through list, compares adjacent elements and swaps if in wrong order. Continues until no swaps needed. Time: O(n²), Space: O(1). Stable but inefficient.
Describe bubble sort algorithm	for i = 0 to n-1: swapped = false, for j = 0 to n-i-2: if array[j] > array[j+1] then swap, swapped = true. if not swapped then break. Each pass moves largest unsorted element to correct position.
What is insertion sort?	Builds sorted array one element at a time by inserting each element into its correct position. Like sorting cards. Time: O(n²) worst, O(n) best (sorted), Space: O(1). Efficient for small/nearly-sorted data. Stable.
Describe insertion sort algorithm	for i = 1 to n-1: key = array[i], j = i-1, while j >= 0 and array[j] > key: array[j+1] = array[j], j = j-1, array[j+1] = key. Maintains sorted portion on left.
What is merge sort?	Divide-and-conquer algorithm that divides array in half recursively, sorts each half, then merges sorted halves. Always O(n log n) time. Space: O(n). Stable. Predictable performance. Not in-place.
Describe merge sort algorithm	function mergeSort(array) if length <= 1 return, mid = length/2, left = mergeSort(array[0...mid-1]), right = mergeSort(array[mid...end]), return merge(left, right). Merge combines two sorted arrays.
What is quick sort?	Divide-and-conquer using pivot to partition array. Elements less than pivot go left, greater go right. Recursively sort partitions. Average: O(n log n), Worst: O(n²), Space: O(log n). In-place. Unstable. Very fast in practice.
Describe quick sort algorithm	function quickSort(array, low, high) if low < high: pivot = partition(array, low, high), quickSort(array, low, pivot-1), quickSort(array, pivot+1, high). Partition rearranges array around pivot.
What is a stable sorting algorithm?	A sorting algorithm that preserves the relative order of elements with equal values. Stable: bubble, insertion, merge. Unstable: quick, selection, heap.
Compare sorting algorithm complexities	Bubble: O(n²) time, O(1) space, stable. Insertion: O(n²) time, O(1) space, stable. Merge: O(n log n) time, O(n) space, stable. Quick: O(n log n) avg, O(n²) worst, O(log n) space, unstable.
What is linear search?	Simple search algorithm checking each element sequentially until target found or end reached. Works on unsorted data. Time: O(n), Space: O(1). Best: O(1) if first. Worst: O(n) if last/not present.
Describe linear search algorithm	function linearSearch(array, target) for i = 0 to length-1: if array[i] = target then return i. return -1 (not found). Simple but inefficient for large datasets.
What is binary search?	Efficient search for sorted arrays. Repeatedly divides search space in half by comparing target with middle element. Time: O(log n), Space: O(1) iterative or O(log n) recursive. Requires sorted data.
Describe binary search algorithm (iterative)	function binarySearch(array, target) low = 0, high = length-1, while low <= high: mid = (low+high)/2, if array[mid] = target return mid, else if target < array[mid]: high = mid-1, else low = mid+1. return -1.
What are the requirements for binary search?	1. Data must be sorted 2. Must support random access (array, not linked list) 3. Data should be static or infrequently updated. If data changes frequently, sorting cost may outweigh benefits.
Compare linear and binary search	Linear: works on unsorted, simple, O(n). Binary: O(log n) very fast, requires sorted data, requires random access. Binary much faster for large sorted datasets.
What are the file access modes?	Read ('r'): open existing for reading. Write ('w'): create new or overwrite. Append ('a'): add to end. Read/Write ('r+', 'w+', 'a+'): combination modes.
What is a text file?	File storing data as human-readable characters using ASCII/UTF-8. Can be opened in text editor. Examples: .txt, .csv, .json. Easy to read but less efficient than binary.
What is a binary file?	File storing data in binary format (0s and 1s) not human-readable. More efficient storage. Examples: .exe, .jpg, .mp3. Requires specific program to read. Faster, smaller file size.
What are the steps for file handling?	1. Open file (specify mode) 2. Read from or write to file 3. Close file (important to free resources). Use try-except blocks, always close files.
What is a CSV file?	Comma-Separated Values file storing tabular data. Each line is record, commas separate fields. First line often headers. Human-readable, widely supported. Example: name,age,grade / Alice,16,A
What is JSON?	JavaScript Object Notation - text format for storing/exchanging data. Uses key-value pairs and arrays. Human-readable, language-independent, supports nesting. Common for APIs. Example: {"name": "Alice", "age": 16}
What is XML?	eXtensible Markup Language - markup for storing/transporting data. Uses custom tags. Hierarchical, self-descriptive, verbose. Example: <student><name>Alice</name><age>16</age></student>
What are file handling errors?	FileNotFoundError: file doesn't exist. PermissionError: no permission. IOError: general I/O errors. EOFError: read past end. Use exception handling to catch these.
What is exception handling?	Mechanism for handling runtime errors gracefully without crashing. Uses try-catch-finally blocks. Separates error-handling from normal code. Makes programs robust and user-friendly.
What is a try-except block?	try block: contains code that might raise exception. except block: handles exception if occurs. Program continues after except. Can have multiple except blocks for different types.
What is a finally block?	Code that always executes whether exception occurred or not. Used for cleanup: closing files, releasing resources. Runs after try and except blocks. Optional but good practice.
What are common exception types?	ValueError: invalid value. TypeError: wrong type. ZeroDivisionError: division by zero. IndexError: index out of range. KeyError: key not in dictionary. FileNotFoundError: file doesn't exist.
What is the raise statement?	Manually triggers an exception. Used for: input validation, enforcing constraints, custom errors. Example: if age < 0: raise ValueError('Age cannot be negative'). Can re-raise caught exceptions.
Why use exception handling?	1. Prevents crashes 2. Provides meaningful errors 3. Separates error handling from logic 4. Enables recovery 5. Makes code robust 6. Improves user experience
What is SQL?	Structured Query Language - standard for managing relational databases. Used to: create/modify structure, insert/update/delete data, query data. Not case-sensitive. Declarative (say what, not how).
What is a relational database?	Database organizing data into tables with rows (records) and columns (attributes). Tables connected via relationships using keys. Examples: MySQL, PostgreSQL, SQLite. Reduces redundancy through normalization.
What is a primary key?	A field (or combination) that uniquely identifies each record in a table. Must be: unique, not null, unchanging. Only one per table. Often ID number. Ensures entity integrity.
What is a foreign key?	A field in one table that references primary key of another table. Creates relationship between tables. Can be null. Multiple per table possible. Ensures referential integrity. Example: StudentID in Enrollment references Students.
What is the SELECT statement?	Retrieves data from database. Syntax: SELECT column1, column2 FROM table WHERE condition ORDER BY column. SELECT * selects all columns. WHERE filters rows. ORDER BY sorts (ASC/DESC).
What is the INSERT statement?	Adds new records to table. Syntax: INSERT INTO table (column1, column2) VALUES (value1, value2). Columns optional if providing all values in order.
What is the UPDATE statement?	Modifies existing records. Syntax: UPDATE table SET column1 = value1, column2 = value2 WHERE condition. WHERE crucial - without it, ALL records updated!
What is the DELETE statement?	Removes records from table. Syntax: DELETE FROM table WHERE condition. WHERE crucial - without it, ALL records deleted! Doesn't delete table structure, only data.
What is a JOIN?	Combines rows from two or more tables based on related column. INNER JOIN: matching records from both. LEFT JOIN: all from left, matching from right. RIGHT JOIN: all from right, matching from left.
What are SQL aggregate functions?	Functions performing calculations on multiple rows: COUNT() number of rows, SUM() total, AVG() average, MAX() largest, MIN() smallest. Example: SELECT COUNT(*) FROM students WHERE grade = 'A'
What is the GROUP BY clause?	Groups rows with same values in specified columns for aggregate functions. Syntax: SELECT column, COUNT(*) FROM table GROUP BY column. Often with HAVING to filter groups.
What is database normalization?	Process of organizing database to reduce redundancy and improve integrity. Involves dividing large tables into smaller ones and defining relationships. Forms: 1NF, 2NF, 3NF. Benefits: less duplication, easier updates.
What is a hash table?	Data structure implementing associative array using hash function to compute index for storing values. Maps keys to values. Average O(1) for insert, delete, search. Also called hash map. Handles collisions.
What is a hash function?	Function converting input (key) into integer (hash code) used as array index. Should be: fast, deterministic (same input → same output), uniform distribution. Good hash function minimizes collisions.
What is a collision in hash tables?	When two different keys hash to same index. Inevitable with finite array. Handling methods: chaining (linked lists at each index), open addressing (find next slot). Too many collisions degrade to O(n).
What is chaining in hash tables?	Collision resolution where each array index stores linked list of all key-value pairs hashing to that index. Advantages: simple, handles many collisions. Disadvantages: extra memory for pointers.
What is the load factor?	Ratio of entries to buckets in hash table. Load factor = n/k (n=entries, k=buckets). High load → more collisions → worse performance. Hash tables resize when exceeds threshold (e.g., 0.75).
What are dictionary operations?	insert/put(key, value): add/update - O(1) average. get(key): retrieve value - O(1) average. delete/remove(key): remove - O(1) average. contains(key): check exists - O(1) average. keys(), values().
What is divide and conquer?	Algorithm design breaking problem into smaller subproblems, solving recursively, combining solutions. Steps: divide, conquer, combine. Examples: merge sort, quick sort, binary search. Often uses recursion.
What is dynamic programming?	Optimization technique solving complex problems by breaking into overlapping subproblems, solving each once, storing results (memoization). Avoids redundant computation. Examples: Fibonacci with memoization, shortest path, knapsack. Bottom-up or top-down.
What is a greedy algorithm?	Algorithm making locally optimal choice at each step hoping for global optimum. Doesn't reconsider choices. Fast but doesn't always give optimal solution. Examples: Dijkstra's, Huffman coding, activity selection. Works when greedy choice property holds.
What is backtracking?	Algorithm technique finding solutions by trying possibilities and abandoning when they fail. Systematic trial and error. Uses recursion. Examples: N-Queens, Sudoku solver, maze solving. Can be slow but guarantees solution if exists.
What is brute force?	Straightforward approach trying all possible solutions and selecting best. Simple but often inefficient. Guaranteed to find solution if exists. Examples: trying all permutations, exhaustive search. Use when: problem small, correctness critical, no better algorithm.
What is a 2D array?	An array of arrays, representing data in rows and columns like a table or grid. Accessed using two indices: array[row][column]. Used for: matrices, game boards, image data, tables. Example: chessboard is 8x8 2D array.
What is infix notation?	Mathematical notation where operator is placed between operands. Standard notation humans use. Example: A + B, (A + B) * C. Requires parentheses for order of operations. Used in most programming languages.
What is prefix notation (Polish notation)?	Notation where operator comes before operands. No parentheses needed. Example: + A B (means A + B), * + A B C (means (A + B) * C). Used in some programming languages like Lisp. Easy for computers to parse.
What is postfix notation (Reverse Polish notation)?	Notation where operator comes after operands. No parentheses needed. Example: A B + (means A + B), A B + C * (means (A + B) * C). Easy to evaluate using stack. Used in some calculators and stack-based languages.
How do you evaluate postfix expressions?	Use a stack. Scan expression left to right: if operand, push to stack; if operator, pop two operands, apply operator, push result. Final stack value is answer. Example: 3 4 + 5 * → push 3, push 4, pop & add (7), push 7, push 5, pop & multiply (35).
How do you convert infix to postfix?	Use stack for operators. Scan infix left to right: if operand, output it; if '(', push to stack; if ')', pop until '('; if operator, pop operators with higher/equal precedence, then push current operator. Pop remaining operators. Outputs postfix expression.
What is operator precedence?	The order in which operators are evaluated in expressions. Higher precedence operators evaluated first. Standard order: parentheses → exponents → multiply/divide → add/subtract. Example: 2 + 3 * 4 = 2 + 12 = 14 (not 20).
What is a static data structure?	Data structure with fixed size allocated at compile time. Size cannot change during execution. Examples: static arrays. Advantages: fast access, simple. Disadvantages: inflexible, wasted space if not full, overflow if too small.
What is a dynamic data structure?	Data structure that can grow/shrink during execution. Size allocated at runtime. Examples: linked lists, dynamic arrays, trees. Advantages: flexible, efficient memory use. Disadvantages: slower access, more complex implementation, memory management overhead.
What is a list data structure?	Ordered collection of elements that can grow/shrink. Elements accessed by index. Supports insertion, deletion, searching, iteration. Can be implemented as dynamic array or linked list. Python lists are dynamic arrays.
What is a tuple?	An immutable ordered collection of elements. Once created, cannot be modified. Elements accessed by index. More memory-efficient than lists. Used for: fixed collections, dictionary keys, returning multiple values. Example: coordinates = (10, 20).
What is the difference between list and tuple?	List: mutable (can change), dynamic size, slower, uses more memory, syntax: [1, 2, 3]. Tuple: immutable (cannot change), fixed after creation, faster, more efficient, syntax: (1, 2, 3). Use tuple for data that shouldn't change.
